# Snow Time 2.0 — дизайн-система

## Три направления и выбор

| Направление | Суть | Плюсы | Минусы |
|---|---|---|---|
| A. Night Summit | Тёмный кинематографичный сайт, широкий гротеск | Эффектно, близко к текущему тёмному сайту | Фото номеров на тёмном фоне выглядят хуже, тяжело читать длинные тексты |
| **B. Alpine Editorial (выбрано)** | Тёплый «снежный» фон, крупная антиква с курсивом, тёмные сцены только для акцентов | Премиально, отлично читается, реальные фото объектов выглядят выигрышно, тёмные секции дают ритм | Требует качественных фотографий |
| C. Adventure Poster | Плакатная типографика, яркий акцент, много движения | Молодёжно, заметно | Меньше доверия у семей и пар, быстрее устаревает |

Выбрано B: основная аудитория (пары, семьи, компании) принимает решение по фотографиям и ясным ценам, а не по эффектам.

## Токены (src/styles/global.css)

- Цвета: `--ink #0b141c` (ночные горы), `--snow #f4f1ea`, `--paper #fbfaf6`, `--glacier #9fd3ee` (преемственность с голубым #79bee5 старого сайта), `--glacier-deep #1f5f86`, `--ember #e0703a` (точечный акцент), `--stone #5a6670`.
- Шрифты: Cormorant (заголовки, курсив для смыслового слова), Manrope (текст и интерфейс). Оба с кириллицей, подключены локально, без запросов к Google.
- Размеры текста: плавная шкала `--step--1 … --step-4` через `clamp()`.
- Отступы: `--gutter`, `--section`; максимальная ширина 90rem.
- Кнопки: `.btn-primary` (голубая), `.btn-ink` (тёмная), `.btn-ghost` (контур). Высота не меньше 52px, заливка «поднимается» снизу при наведении.

## Motion-система (src/scripts/motion.js)

- Первый экран: медленный «наезд» фото, построчное появление заголовка, параллакс фона при прокрутке.
- Прокрутка: построчные заголовки, масочное раскрытие фото, параллакс вторых фото, текст-манифест проявляется по словам, счётчики, линия маршрута.
- Микровзаимодействия: кнопки, ссылки, строки дат, шаги мастера подбора, смена цены в калькуляторе.
- Анимируются только transform, opacity и clip-path. На телефоне параллакс упрощён. При `prefers-reduced-motion` всё показывается сразу, без движения.
- Плавная «инерционная» прокрутка намеренно не используется: она мешает на телефоне и с клавиатуры.

## Правила

- Фото объектов только настоящие. ИИ-изображения допустимы лишь для атмосферных фонов.
- Цены, телефоны и даты берутся из `src/data/*.json`, в вёрстке не дублируются.
- Никаких таймеров, выдуманного дефицита мест и отзывов без источника.
