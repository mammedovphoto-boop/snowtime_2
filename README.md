# Snow Time 2.0

Демо нового сайта [snowtime.ge](https://snowtime.ge) на Astro: главная, туры и трансферы с анимацией, мастером подбора отдыха и калькулятором трансфера.

- `npm install`, затем `npm run dev` — локальный запуск.
- `npm run build` — сборка в `dist/` (для Cloudflare Pages: команда `npm run build`, папка `dist`).
- `PREVIEW=1 npm run build` — плоские .html-файлы для предпросмотра без сервера.

Документы: [DESIGN.md](DESIGN.md), [аудит](docs/AUDIT.md), [статус и вопросы](docs/STATUS.md).
Данные для правок: `src/data/*.json`.

Действующий сайт не затронут. Домен переключается только с разрешения владельца.
